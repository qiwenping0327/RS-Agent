# 文档类型模板库

> 使用方式：选取对应骨架，替换各节括号内提示为实际内容；不适用的节可删除，但删除"方法说明/参考文献"等核心节需向用户说明理由。

## 模板 A：研究报告 / 行业分析

```markdown
# {报告标题}

**摘要**（150–300 字：研究对象 → 核心发现 → 关键数据 → 主要建议）

## 1 研究背景与范围
### 1.1 背景与问题定义        （行业痛点 / 为什么现在研究）
### 1.2 研究范围与方法        （时间范围、数据来源、分析方法）

## 2 现状分析
### 2.1 市场规模与结构        （总量 + 细分结构表）
### 2.2 竞争格局              （头部玩家对比表：份额/定位/优劣势）
### 2.3 政策与监管环境        （关键政策条款 + 影响分析）

## 3 驱动因素与挑战
### 3.1 核心驱动因素          （逐条：因素 + 证据 + 影响路径）
### 3.2 主要挑战与风险        （风险矩阵表：概率 × 影响）

## 4 趋势研判
### 4.1 短期（1 年）          （可验证的判断 + 依据）
### 4.2 中长期（3–5 年）      （情景推演：基准/乐观/悲观）

## 5 结论与建议
### 5.1 核心结论              （3–5 条，每条一句话）
### 5.2 行动建议              （分对象：企业/投资者/监管）

## 参考文献
```

## 模板 B：技术方案 / 架构设计

```markdown
# {方案名称}技术方案

**摘要**（目标 → 核心选型 → 关键指标）

## 1 需求与目标
### 1.1 业务需求              （用户故事或场景清单）
### 1.2 非功能需求            （性能/安全/合规指标，量化）
### 1.3 约束条件              （预算、技术栈、时间窗口）

## 2 总体设计
### 2.1 架构总览              （分层架构文字图 + 职责说明）
### 2.2 核心流程              （关键链路时序描述）

## 3 关键选型与权衡
### 3.1 备选方案对比          （对比表：方案 × 性能/成本/复杂度/风险）
### 3.2 选型结论与理由        （为什么选 A，放弃 B/C 的代价是什么）

## 4 详细设计
### 4.1 模块设计              （逐模块：职责、接口、数据结构）
### 4.2 数据模型              （实体关系与关键字段表）
### 4.3 异常与降级            （失败场景清单 + 处理策略表）

## 5 实施计划
### 5.1 里程碑                （阶段表：目标/产出/验收标准）
### 5.2 风险与预案

## 附录：术语表
## 参考文献（引用的标准/官方文档）
```

## 模板 C：调研 / 评估报告

```markdown
# {对象}调研评估报告

**摘要**（评估对象 → 方法 → 总体评级 → 主要发现）

## 1 评估背景与目的
## 2 评估方法
### 2.1 评估维度与权重        （维度表：维度/权重/依据，权重需说明理由）
### 2.2 数据来源              （问卷/访谈/实测/二手资料，样本量）

## 3 分维度评估
### 3.1 维度一：{名称}        （评分 + 证据 + 与基准对比）
### 3.2 维度二：{名称}
### 3.3 维度三：{名称}

## 4 综合评估结果
### 4.1 评分汇总              （雷达/汇总表 + 排序解读）
### 4.2 优势与短板            （分列，每条附证据）

## 5 改进建议（按"高性价比 → 长期"排序，每条：问题 → 建议 → 预期收益 → 成本）

## 附录：评估明细数据
## 参考文献
```

## 模板 D：综述 / 白皮书

```markdown
# {主题}综述（白皮书）

**摘要**

## 1 引言（问题域定义、综述范围与检索方法）

## 2 发展脉络
### 2.1 阶段一：{时期/范式}    （标志性工作 + 突破点 + 局限）
### 2.2 阶段二：{时期/范式}
### 2.3 阶段三：{时期/范式}

## 3 技术路线对比
（路线 × 代表工作 × 优劣 × 适用场景 对比表）

## 4 关键挑战
（挑战 1/2/3，每个：现状 → 根因 → 现有尝试的不足）

## 5 趋势与展望
（3–5 个趋势判断，每个附依据与置信度）

## 6 结论

## 参考文献（综述类 25+ 条为佳，覆盖近 3 年工作 ≥40%）
```

## 通用写作约定

1. 章节编号到三级标题为止，四级用加粗段落标题。
2. 每章开头 1–2 句"导语"交代本章结论与结构。
3. 全文交付前统计字数并在文档开头元信息注明（目标读者/日期/版本）。
4. 落盘文件名：`{YYYYMMDD}-{文档标题}.md`。
