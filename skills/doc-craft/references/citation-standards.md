# 引用与可信来源规范

## 1. 来源可信度分级（取舍优先级从高到低）

| 等级 | 来源类型 | 示例 |
|---|---|---|
| A | 官方一手来源 | 政府公报、统计数据局、上市公司年报、标准文本（ISO/GB）、法院判例 |
| B | 权威机构与同行评议 | 学术期刊论文、行业白皮书（IDC/Gartner/中国信通院）、技术标准草案 |
| C | 专业媒体与官方博客 | 央媒、头部科技媒体、项目官方发布（release notes / RFC） |
| D | 自媒体与论坛 | 公众号文章、知乎、博客 — 仅作线索，需回溯到 A/B/C 才可引用 |

规则：
- 核心论断只用 A/B 级来源；C 级需交叉验证后使用；D 级不得直接作为论据。
- 同一事实有多个来源时，引用最高等级来源。
- 找不到可靠来源的论断：要么删除，要么改写为观点并注明"作者判断"。

## 2. 引用标注方式

### 文内标注（正文中）
- 数字编号制（默认，适合中文报告）：`……市场规模达 213 亿元 [1]。`
- 多来源：`[1][2]`；页码/章节：`[1]§3.2`。
- 作者-年份制（学术风格）：`（Zhang et al., 2023）`。

### 文末参考文献列表
- 位置：文档末尾"参考文献"一级章节。
- 排序：按正文首次出现顺序编号（数字制）或按作者字母序（作者-年份制）。
- 正文每处 `[n]` 必须能在列表中找到；列表条目必须至少被正文引用一次——两边互查。

## 3. 参考文献著录格式

### GB/T 7714-2015（中文文档默认）

```
[序号] 作者. 题名[文献类型标识]. 出版地: 出版者, 出版年: 页码. 

期刊：[1] 李四, 王五. 遥感影像云检测综述[J]. 测绘学报, 2023, 52(4): 611-625.
网页：[2] 自然资源部. 2024年卫星遥感应用报告[EB/OL]. (2025-03-12)[2026-08-27]. https://...
图书：[3] Barbara Minto. 金字塔原理[M]. 北京: 民主与建设出版社, 2019.
标准：[4] GB/T 7714-2015 信息与文献 参考文献著录规则[S].
```

文献类型标识：[J] 期刊、[M] 图书、[EB/OL] 网络、[C] 会议录、[D] 学位论文、[S] 标准、[R] 报告。

### APA 7th（英文/学术场景）

```
Zhang, S., & Li, W. (2023). Cloud detection in remote sensing: A survey. 
IEEE Transactions on Geoscience and Remote Sensing, 52(4), 611-625.
```

## 4. 网络来源引用要点

- 必须给出可直接访问的 URL；链接失效风险高的（社交媒体）注明获取日期。
- 数据类引用注明**统计口径与发布时间**：`(2025-03-12)[2026-08-27]` 中前者为发布日期、后者为引用日期。
- 英文链接标题保留原文，不在参考文献里翻译。

## 5. 引用密度参考

| 文档类型 | 建议 |
|---|---|
| 研究报告 / 综述 | 全文 15+ 条，每章 3+ 条 |
| 技术方案 | 5~10 条（标准、官方文档为主） |
| 评估报告 | 关键结论处每条 1~2 个来源 |
| 观点短文 | 核心论断处标注即可 |

## 6. 诚信红线（禁止）

1. 编造不存在的文献、作者、数据、URL。
2. 把 D 级来源包装成权威来源（"有研究表明"但不给出处）。
3. 截取断章取义——引用结论要保留原文限定条件。
4. 无法访问原文时假装读过——应标注"转引自"。
