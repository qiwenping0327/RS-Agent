# 交付前质量自查清单

> 定稿后逐项检查，任何一项不过先修复再交付。检查结果在交付说明中简要报告（如"自查 12/12 通过，第 3 项已修复"）。

## A. 结构完整性

- [ ] A1 摘要先于正文出现，且 150–300 字内覆盖"对象/发现/结论"
- [ ] A2 章节编号连续，无跳号；目录层级 ≤ 三级
- [ ] A3 各章符合 MECE：不重叠、不遗漏（回看大纲逐章核对）
- [ ] A4 每章首段有导语（本章结论 + 结构预告）
- [ ] A5 结论章与摘要呼应，无正文未出现过的新事实

## B. 逻辑与深度

- [ ] B1 核心论断均可回溯到"论据链"（观点→证据→引用），无裸断言
- [ ] B2 关键主题完成三层展开（是什么/为什么/怎么办），无浅尝辄止
- [ ] B3 对比类信息已表格化，表格有编号、标题、来源
- [ ] B4 量化表述优先：无"大幅/显著/很多"等无数据修饰（确无数据时改为定性说明并注明依据）
- [ ] B5 删除了空洞段落：每段都有信息增量

## C. 引用与事实

- [ ] C1 文内标注 [n] 与文末参考文献一一对应（双向核对）
- [ ] C2 核心论断来源等级 ≥ B 级（官方/同行评议/权威机构）
- [ ] C3 无编造的文献、数据、URL（不确定的已标注"待核实"或删除）
- [ ] C4 数据引用带年份与口径
- [ ] C5 引用结论保留原文限定条件（无断章取义）

## D. 格式规范

- [ ] D1 术语全文一致，首次出现给全称+缩写
- [ ] D2 中英文与数字间有空格；单位规范（亿元/GB/万人次）
- [ ] D3 图表编号连续且被正文引用（"见表 1"）
- [ ] D4 无残留占位符（{xxx}、"TODO"、"此处省略"）
- [ ] D5 文件已落盘为 .md（文件名 `YYYYMMDD-标题.md`），文档头含元信息（读者/日期/版本/字数）

## E. 用户需求符合性

- [ ] E1 覆盖了用户明确指定的章节/格式要求（对照原始需求逐条勾）
- [ ] E2 篇幅在约定范围内（±20%）
- [ ] E3 语言深浅匹配目标读者（决策者看结论，技术人员看细节均已兼顾）
- [ ] E4 敏感/不确定内容已向用户说明边界
